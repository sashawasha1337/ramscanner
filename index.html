RAM Stick Log

Paste or scan what's printed on each stick. It'll pull out generation, speed, voltage, ECC/buffering, capacity and rank/width where the label makes that decodable, and flag whatever it can't figure out so you can fill it in by hand. Manufacturer-specific part numbers (Samsung, Hynix, Micron, etc.) are identified but not fully decoded — check that maker's datasheet for exact density if you need it.

If a stick has more than one barcode (e.g. an OEM part-number code plus a manufacturer spec code), scan both before hitting "Add to log" - each scan adds a new line instead of replacing the last one, so both get decoded together as one entry.

Barcodes on these labels are usually a serial/lot code, not the spec line. "Read printed text" instead photographs the label and OCRs the actual printed part-number and "4GBxRxN PCx-xxxxx" text - often more useful than the barcode for this data. Fill the frame with just the label (not the whole stick) for best results, and always review what it reads before adding, since OCR can misread characters.
