RAM Stick Log

Paste or scan what's printed on each stick. It'll pull out generation, speed, voltage, ECC/buffering, capacity and rank/width where the label makes that decodable, and flag whatever it can't figure out so you can fill it in by hand. Manufacturer-specific part numbers (Samsung, Hynix, Micron, etc.) are identified but not fully decoded — check that maker's datasheet for exact density if you need it.

Tips: hold ~20-30cm back so the camera can focus, use even bright light with no glare, fill most of the frame with the barcode, keep it level. If the label uses a small square 2D code (Data Matrix) rather than a striped barcode, scanning won't read it - type the printed part number in manually instead.
